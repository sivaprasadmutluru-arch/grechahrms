# Grecha HRMS web

React/Vite application. Run `npm ci` then `npm run dev`. API defaults to `http://127.0.0.1:8080`; override with `VITE_API_TARGET`.

Production build: `npm run build`. The build writes to sibling `../hrms/src/main/resources/static` for packaging with the backend. This repository contains source, not production secrets or a deployed build.
